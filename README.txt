Important:
This is a complete offline-ready Progressive Web App package.
For iPhone/iPad installation, the folder must be uploaded to a secure HTTPS web host.
Then open index.html in Safari and choose Share > Add to Home Screen.

The app currently:
- Stores customers
- Stores saved jobs
- Supports alarm, CCTV, electrical, fire alarm, emergency lighting, and network jobs
- Adds photos
- Captures signatures
- Prints/saves PDF reports
- Exports/imports backups

Cloud syncing, automatic email sending, user accounts and multi-device live sync require a backend and hosting service.
