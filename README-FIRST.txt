INSTALL ON GITHUB PAGES
1. Open your cables-pro GitHub repository.
2. Delete or replace the old website files.
3. Upload every file from this ZIP to the ROOT of the repository.
4. Keep GitHub Pages set to:
   Branch: main
   Folder: /(root)
5. Wait around one minute, then refresh your existing Pages address.

INSTALL ON IPHONE
1. Open the GitHub Pages website in Safari.
2. Press Share.
3. Select Add to Home Screen.
4. Name it Cables Pro.

IMPORTANT DATA NOTE
This release stores customer and job records locally in Safari on that device.
Use Settings > Export Backup regularly.
It does not yet provide encrypted cloud storage, secure user accounts, automatic cross-device syncing or direct server email delivery.
